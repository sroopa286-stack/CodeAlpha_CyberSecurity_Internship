# CodeAlpha Cyber Security Internship

This repository contains two completed internship tasks. All examples are educational, local-only demonstrations. They do not target real services, collect credentials, inspect live traffic, or interact with phishing websites.

## Tasks included

| Task | Folder | Deliverables |
|---|---|---|
| Task 2: Phishing Awareness Training | `task-2-phishing-awareness/` | Presentation, interactive quiz, facilitator notes |
| Task 3: Secure Coding Review | `task-3-secure-coding-review/` | Sample application, reviewed code, security review report |

## Quick start

### Task 2

Open `task-2-phishing-awareness/Phishing_Awareness_Training.pptx` to present the module. Open `task-2-phishing-awareness/quiz.html` in a browser to take the five-question quiz locally.

### Task 3

The insecure file is **review material only**. Do not deploy or reuse it.

```powershell
cd task-3-secure-coding-review
python secure_app.py
```

The secure example creates a local `secure_demo.db` file and demonstrates validation, parameterized database queries, password hashing, generic login errors, and safe audit logging.
